# jackbox-images
jackbox survive the interent custom images setup script

youll need a folder of custom pictures, the jackbox survive the internet has 132 possible images 
so youll need 132 custom images if you want to replace them all, but the script will work even without
its just that some images will not be custom

if the window asking for folder path is giving issues you can modify the variables
```
customImages = ""
jackboxImages = ""
```
if you put in them the path it will not give the folder selection window
the first window is to select the folder where you have custom images, and the second is where the jackbox images are
the jackbox images path will look something like this if you are on linux and didnt download it using steam:
/home/user/The-Jackbox-Party-Pack-4-SteamRIP/The Jackbox Party Pack 4/games/SurviveTheInternet/content/STIPhoto/
otherwise you can right click on the game entry in steam, go to properties, files
in there find games,SurviveTheInternet/content/STIPhoto
this is the path youll need for the second window
